## QQ 远程服务

- 私人远程服务新增 QQ 结构化交互。兼容原有服务器、绑定凭据和微信历史记录，已有绑定通常无需重新绑定。新用户的远程服务默认关闭。
- 向兼容的 QQ Bot 发送 `/today`、`/tomorrow`、`/week` 或 `/ddl` 可直接查询本地日历，无需调用模型。
- 确认、取消和选择候选可使用卡片按钮。引用查询卡片时，可按原编号指定同名或不同名事项。修改仍需确认；事项变化后请重新查询。
- 可发送「撤销」，也可引用原操作回复「撤销」。高风险删除继续需要两次确认。旧服务器保留纯文本兼容。

## 设置与升级

- 「AI 设置与隐私」优化了远程服务的标签、连接卡片与历史记录布局。历史记录显示实际消息来源。
- Windows 继续提供便携 ZIP 和独立修复工具，升级沿用原有 SQLite 数据及 Windows 用户凭据。
