# Desktop Calendar v0.9.2 — 习惯与日程管理升级

## 习惯 2.0

- 支持每天、指定星期、每月、每年及自定义间隔周期，也可设置开始与结束日期。
- 新增实时周期摘要和更清晰的星期选择；每天习惯仍然可以快速创建。
- 保留已有打卡历史，按计划执行日统计，非计划日不再混作漏打卡。

## 批量管理

- Global 月度排期和时间轴支持 Ctrl+单击多选，多日事项只计一项；时间轴还支持 Shift 范围选择。
- 可批量完成、取消完成、分类、提前或延后日期，以及双重确认删除。
- 每批操作可一次撤销、一次重做；保存失败不会留下半批结果。

## 体验优化

- 精修习惯周期编辑器、多选高亮、批量工具栏和日期调整弹窗。
- 分类菜单显示颜色，批量操作反馈包含数量，删除提示明确可撤销。
- 适配 Modern、Windows 7 Glass、Paper、Frutiger Aero 及高 DPI，保留现有备份恢复和独立更新器。

## 下载与升级

下载 `DesktopCalendar-win64.zip`，完整解压后运行 `DesktopCalendar.exe`，不要单独移动 EXE。
升级不会覆盖个人日程；建议先通过“数据管理 → 备份数据”保留一份备份。

主程序无法启动时，可运行包内或单独下载的 `DesktopCalendarRepair.exe` 检查更新或重新安装。
ZIP 和修复工具均附 SHA256 校验文件。

注意：多选和撤销历史仅保留在当前会话；批量工具栏不操作习惯，也不会整批拖动事项。
