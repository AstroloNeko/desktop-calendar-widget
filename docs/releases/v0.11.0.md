## SQLite 存储升级

- v0.11.0 引入 SQLite 存储。v0.10.x 用户可通过主界面“升级到 SQLite”或“更多 → 数据管理”主动迁移；不会静默迁移。
- 升级前严格校验并保留原 JSON 和迁移前保护副本。激活后 SQLite 是唯一权威存储，不支持直接用旧版 EXE 回退。
- 支持旧 Format 1 和新 Format 2 备份、一致性 SQLite 备份以及 `--recover-storage` 离线灾难恢复。
- 恢复旧备份可能导致历史提醒再次投递，恢复前会明确提示并要求确认。
- 完善业务事务、应用生命周期和更新器兼容保护。

## 下载

- 正常使用：下载并解压 `DesktopCalendar-win64.zip`，运行其中的 `DesktopCalendar.exe`。
- 程序无法启动时：可使用独立的 `DesktopCalendarRepair.exe` 修复程序文件；恢复日历数据请使用备份恢复流程。
- SHA-256 校验文件随附件提供。日历备份不包含外部 AI 配置、凭据或 ChatJournal。
