## Calendar Agent

- 通过已配置的 DeepSeek 兼容服务，自然语言查询、新建和修改日程。可用备忘录式输入快速记录一项或多项安排；同名事项可先选择目标，跨日表述有歧义时先澄清。
- 保留待确认操作以便续办；删除仍需确认。界面区分已保存、无变化与结果待核查，不把模型文本当作写入凭证。
- 全局视图右栏可直接使用 AI 助理；当日详情继续提供事项列表与快速添加。默认按 `Ctrl+Alt+J` 唤起独立助手，可在「更多 → 快捷键设置」自定义。

## 日历与数据

- 全新环境默认使用 SQLite；已有 JSON 用户仍自主决定是否升级。「继续使用 JSON，不再提醒」会在本机保留，不影响以后手动升级。
- 支持显式导入旧 Schema 8/9 JSON。空 SQLite 可在校验转换后导入；非空 SQLite 不提供静默覆盖或合并，历史备份仍通过单独确认的恢复流程处理。
- 升级保留原 JSON 和保护副本；SQLite 激活后不回退旧 JSON。恢复历史备份可能再次投递部分提醒。

Windows 使用便携 ZIP。AI 功能需要自行配置模型服务和密钥并同意发送必要上下文；本机 HTTP API 仍为可选、带认证的回环接口。
