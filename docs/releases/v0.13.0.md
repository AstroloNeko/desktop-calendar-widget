## 微信远控

- 私人远程服务默认关闭。配置自己的服务后，可用激活码绑定，也可手动填写 Worker Token。凭据由当前 Windows 用户的 DPAPI 保护。
- 实时通知会唤醒本机领取任务。支持手动检查、断线期间的备用轮询和可选在线兜底检查。系统托盘与设置页显示连接状态，设置页分别显示最近成功检查、检查结果和本机处理记录。
- 绑定失效时可在设置中重新绑定。真实双设备验收尚未完成，已有模拟双用户会话隔离测试。

## 日历助理

- 删除一个或最多五个明确指定的事项，核对清单后确认一次即可。范围性删除和大批删除继续要求两次确认。
- 清单会校验目标是否变化。成功删除可撤销。微信回执会列出实际事项与重要结果，并单独提示失败或结果待核验。

Windows 使用便携 ZIP。升级沿用原有日历存储和 Windows 用户配置。
