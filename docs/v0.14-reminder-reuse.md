# v0.14.0 提醒与每日行程的复用入口

| 现有模块 | 可复用内容 |
| --- | --- |
| `event_commands.py` | `EventChange` 和 `BatchChange` 能提供变更前后状态、受影响日期和 DDL 变化。业务事务提交成功后才使用这些信号。 |
| `calendar_event_service.py` | `EventOperationResult` 统一变更回执和 `reminders_changed`。可用它使本机推送计划失效，再从权威仓库读取新快照。 |
| `desktop_calendar/reminders/reminder_engine.py` | 复用 `ReminderEngine` 的计划计算、到期过滤、去重和补发语义。新传输端可使用独立送达台账。 |
| `calendar_core.py`、`desktop_calendar/storage/sqlite_calendar_repository.py` | 本机仓库保留日历权威性。日期范围和 DDL 计算继续使用现有 `event_dates`、`event_has_deadline` 逻辑。 |
| `desktop_calendar/remote_service.py`、`remote_interaction.py` | 可复用已核验服务器与内部账号隔离、请求重传、结构化事项摘要。主动消息与答复队列的调用语义需要另定。 |

本轮仅记录入口，主动提醒、每日行程、完整云端同步留到下一版本。
