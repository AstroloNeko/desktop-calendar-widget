# v0.14.0 Windows x64 候选验收手册

先校验 ZIP 的 SHA-256，再解压到独立目录。从 `QA-Candidate.json` 核对客户端和云端提交、夹具日期。获准后用 `Start-Isolated-QA.cmd` 启动。启动器首次复制随包合成 SQLite 日历，后续复用同目录下的 `qa-profile`。默认未配置远程和 AI 凭据，Windows 推送与 QQ 推送均关闭。保留压缩包中的种子，重测可另选解压目录。

合成数据包括当天会议、已完成事项、全天事项、今日／逾期／未来 DDL、一项每周习惯及八个同分钟事项。夹具日期与验收当天不同时，预览可切换内置示例，或在隔离档案中调整合成日期。通知生命周期与 DPI 测试另有固定或动态时钟夹具。

## 人工验收记录

| 场景 | 验证内容 |
| --- | --- |
| Modern／Slate，96 与 192 DPI | 紧凑顶栏图标与间距、全局视图、置顶徽标、右栏开合、窄屏贴右、快捷入口恢复 |
| 全局工作区 | 分类和 DDL 分隔、批量栏、搜索首组恢复、嵌入 AI 助手下拉与确认按钮 |
| 提醒中心 | 四栏可访问。检查提醒计划筛选、刷新、选中状态、晨晚预览，以及完成事项从待办中移除 |
| 即时提醒 | 关闭默认即时提醒后检查独立定时规则，验证完成和稍后提醒状态 |
| Windows 通知 | 获准后检查手动试发、八项聚合、横幅、通知中心和点击动作。分别记录系统提交、横幅可见、通知中心和点击结果 |
| QQ 和真实模型 | 单独授权后使用专用测试账号、合成数据和明确的凭据路径。记录协商能力、晨晚格式、隐私试发及回执 |

涉及真实通知、系统注册、手动点击或外部服务时，使用一次性测试会话。不要配置正式客户端的服务或数据。候选包只准备环境，不在构建阶段启动程序。记录日期、Windows 构建号、主题、实际 DPI、候选提交和结果。

## 已授权后的原生入口

从同一客户端提交的仓库或源码归档执行。Windows 原生发送需要先为该源码构建原生通知 DLL。

```powershell
py -3 tools/run_tests.py --desktop-script check_frameless_global --allow-desktop -- --layout-only
py -3 tools/run_tests.py --desktop-script check_global_sidebar --allow-desktop -- --theme modern --dpi 96
py -3 tools/run_tests.py --desktop-script check_global_sidebar --allow-desktop -- --theme modern --dpi 192
py -3 tools/run_tests.py --desktop-script check_global_sidebar --allow-desktop -- --theme slate --dpi 96
py -3 tools/run_tests.py --desktop-script check_global_sidebar --allow-desktop -- --theme slate --dpi 192
py -3 tools/run_tests.py --desktop-script check_reminder_ui_special --allow-desktop -- --output $qaUiOutput
py -3 tools/run_tests.py --desktop-script check_reminder_v0140 --allow-desktop -- --theme modern --send-native --output $qaToastOutput
py -3 tools/run_tests.py --desktop-script check_reminder_ef_native --allow-desktop -- --send-native --output $qaNativeOutput --modes test brief snooze
```

## 准备好的最小 Live 模型评测

下列命令仅供另行授权后执行，需要显式选择独立的 `$qaModelConfig`。使用合成 SQLite、合成日历与固定时钟。第一组验证晨晚启用、关闭晚间和默认即时提醒的确认，第二组验证关闭默认即时提醒后仍保留明确提醒计划，以及绝对提醒时刻。两组调用预算分别为 8 和 6。

```powershell
py -3 -m tools.calendar_agent_eval_reminder_runtime --live --config $qaModelConfig --suite config --cases default-instant-off enable-brief enable-evening disable-evening --max-calls 8
py -3 -m tools.calendar_agent_eval --mode live --config $qaModelConfig --dataset tools/calendar_agent_eval_reminder_cases.json --cases rb11-master-off,rb02-absolute-hplc --max-calls 6
```
