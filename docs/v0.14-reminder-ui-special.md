# v0.14.0 提醒中心 UI 专项整改

## 修改要点

- 以实际「AI 助理设置」为视觉基准。提醒中心复用其选项卡样式、`SettingsScroll`、底栏按钮和 Modern 卡片外壳。提醒中心的下拉、表格和按钮样式单独命名。AI 设置窗口的组件实现保持原样。
- 默认窗口为 760 × 700 逻辑像素，按显示器工作区限制，最小尺寸目标为 480 × 480。标题、选项卡和操作栏固定，四页分别滚动。短字段为 108 × 34 逻辑像素，右对齐。切换页签保留未保存配置。
- 简报使用真正的消息卡预览。宽窗并排显示表单和预览，窄窗堆叠显示。预览复用现有分组和去重逻辑，随草稿内容和隐私选项更新。固定日期的验收夹具标为演示数据。两个快捷按钮为样式预览。
- 通道页把 Windows 实测状态、QQ 核验状态、最近测试结果、隐私和调度扫描分开呈现。远端目前只返回可核验账号标识，界面直接展示该标识。日程与 DDL 的 QQ 偏好沿用现有共同开关。重绑后不沿用旧账号的测试结果。
- 提醒计划在表格中分别投影 Windows 与 QQ 的持久化状态。越过到期时间且仍待处理的事项归入「需要处理」。完整聚合和失败原因可在「通知明细」中查看。主列表使用单一纵向滚动条。

## Windows 验收

- 物理显示器 DPI 为 192（200%）。Modern 与 Paper 分别运行正常和小尺寸。96、120、144 DPI 是同一 Windows 客户端的逻辑布局模拟。
- 专项夹具覆盖 28 条及空列表、选中与未选中、异步状态栏、表单草稿跨页保留、简报启停、DDL 字段依赖及两条通知通道的独立显示。QQ 已绑定与接口异常使用隔离夹具，真实主动推送接口和真实账号仍待云端联调。
- 实际打开提醒计划时，WinRT 一次提交 8 项合成提醒。该次只有一次发送尝试，明细可查到全部 8 项，Tk 心跳最大间隔 73 毫秒。该记录证明提交，系统是否展示通知由 Windows 策略决定。
- 全量回归 1,457 项通过。专项、WinRT 与全量日志位于独立 worktree 的 `build/reminder-ui-special/`。
