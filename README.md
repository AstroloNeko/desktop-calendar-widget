# 桌面月历 Desktop Calendar

一个轻量的 Windows 桌面月历挂件：像经典 Win7 Gadget 一样停留在桌面层，不遮挡普通应用，同时提供 DDL、颜色分类、事项类型和提前提醒。

当前版本：**v0.9.1**。新增完整数据备份、安全恢复和自动安全备份，改善更新日志阅读，并正式附带独立修复更新器。Global 工作台继续支持月度排期与任务时间轴、拖拽排期、撤销/重做和 Ctrl+K 搜索。

## 下载和使用

1. 在 [Releases](https://github.com/AstroloNeko/desktop-calendar-widget/releases) 下载 `DesktopCalendar-win64.zip`。
2. 解压到任意可写目录。
3. 双击 `DesktopCalendar.exe`。

软件默认位于普通应用窗口后面；按 `Win+D` 可以快速回到桌面查看。单击月历会临时进入普通前台，切换到其他应用后自动回到桌面层；只有需要持续覆盖其他窗口时，才需要点击顶部状态切换为“置顶”。

点击右上角横线或按 `Alt+F4` 只会把月历隐藏到系统通知区域，日程提醒和习惯清单仍会继续运行；需要完全退出时，请右键托盘图标选择“退出桌面月历”。

不要只把 EXE 单独移出解压目录；程序旁边的 `_internal`、`DesktopCalendarUpdater.exe` 和 `DesktopCalendarRepair.exe` 都应保留。

## 功能

- 372 像素宽的无边框桌面挂件，可拖动并记忆位置
- Global 无边框大窗口：月度排期与任务时间轴共享数据，支持任务栏最小化/恢复和返回紧凑视图
- 两种 Global 视图支持移动事项、拖动端点调整日期，预览不写入数据，释放后一次保存，Esc 取消
- 事项操作支持 Ctrl+Z / Ctrl+Y 撤销重做；默认 100 步会话历史，文本输入优先保留自身撤销
- Ctrl+K 搜索历史/未来事项的标题、备注、分类，并执行日期跳转和常用命令
- 桌面模式与临时置顶模式
- 桌面模式支持点击临时前台、失去交互后智能归位
- 月历色点、当天日程、逾期状态和完成状态
- 习惯清单：习惯按工作日打卡并在下个工作日重现，待办完成一次后结束
- 习惯清单可独立设置提醒时间，节假日和请假日自动跳过、调休工作日照常提醒
- 单击日期查看，双击日期打开当天完整事项详情，右键打开快捷菜单
- 快速输入支持选择颜色和一般/紧急/DDL 三种事项类型，按 Enter 保存
- 颜色分类、事项类型、备注和多种提前提醒
- 日程时间可留空；无具体时间的事项按当天结束计算，且不触发定时提醒
- 日程可设置持续 1～365 天，只保存一次并在覆盖的每一天显示
- 跨日事项可按有效工作日展开，自动跳过周末、法定假期及手动请假/放假日
- 日期可手动标记为正常、请假或放假，并在重启后保留
- DDL 事项提供日期提示、临近截止汇总和 24 小时内强制置顶区域
- 提醒弹窗支持稍后 10 分钟与直接完成
- 未来 7 天和逾期事项汇总
- 系统通知区域常驻图标，支持显示月历、新建、回到今天、更新和退出
- 中国大陆 2026 年法定节假日/调休，以及 2024—2030 年常用公历与农历节日
- 日程区展开/收起、透明度调整和多显示器边界保护
- 可选开机启动、完整数据备份/安全恢复和单实例保护
- 从 GitHub Releases 检查、校验、下载并自动安装更新

日程数据保存在 `%APPDATA%\DesktopCalendar\calendar_data.json`，升级软件不会覆盖个人数据。

### 备份与恢复

在右上角“更多 → 数据管理”中选择“备份数据…”可导出 `.dcalbackup` 文件。
它保存全部事项（含 DDL、多日排期、分类及颜色）、习惯记录、提醒历史、假期与设置；不包含程序、更新下载包、日志或缓存。
备份为带格式版本、应用版本、创建时间及 SHA256 校验的 ZIP 容器，不加密，请妥善保存个人安排。

“恢复数据…”会先检查备份，再显示来源信息并请求确认。恢复前必须先成功保护当前数据；恢复失败会回滚原数据，成功后清空当前会话撤销历史，避免旧命令修改恢复结果。
恢复替换的是全部数据，不是合并导入。事项、主题和偏好立即重载，窗口位置按现有安全边界规则恢复；保留当前 Compact / Global 工作模式。

每日首次启动（距上次成功自动备份满 24 小时）以及 Schema 迁移、恢复和更新前会创建安全备份，存放在 `%APPDATA%\DesktopCalendar\backups`，保留最近 10 份有效自动备份。
只清理这个受控目录内已验证的自动备份，不清理手动导出、未知或损坏的文件。每日备份失败不打断使用，可在数据管理菜单查看提示；恢复和更新前的保护备份失败会中止操作。
单份用户数据安全上限为 32 MB。SHA256 用于发现损坏，不是来源签名；只恢复可信来源的备份。

法定放假与调休按年度公布，当前内置 2026 年国务院办公厅安排；常用节日可在右上角菜单中关闭显示。

## 自动更新

打开右上角 `···` 菜单，点击“检查更新”。如果 GitHub Releases 存在更高版本，软件会：

1. 下载 `DesktopCalendar-win64.zip`；
2. 使用 Release 中的 `.sha256` 文件校验完整性；
3. 启动独立更新器并关闭当前版本；
4. 覆盖程序文件并自动重启。

源码模式只检查版本，不会覆盖源码；自动安装仅在打包后的发布版中启用。

### 主程序无法启动时

双击 `DesktopCalendarRepair.exe`，点击“检查并修复”。它可以放在月历安装文件夹内；若单独下载到别处，启动时按提示选择原来的月历安装文件夹。它不依赖月历主窗口，可以下载并校验最新正式包；即使最新版本与当前版本相同，也能重新安装程序文件。修复前请先从通知区域完全退出仍在运行的月历。个人事项、习惯与设置保存在 `%APPDATA%\DesktopCalendar\calendar_data.json`，修复程序不会删除这个文件。

如果旧安装包没有 `DesktopCalendarRepair.exe`，可从后续 [GitHub Releases](https://github.com/AstroloNeko/desktop-calendar-widget/releases) 单独下载此修复程序，或下载新版 ZIP 并解压。当前 v0.8.2 发布包尚不包含此工具。

## 常用操作

| 操作 | 效果 |
|---|---|
| 单击日期 | 查看当天日程 |
| 双击日期 | 打开当天完整事项详情 |
| 右键日期或日程 | 打开快捷菜单 |
| 单击日程 | 编辑日程 |
| 单击日程或习惯清单左侧方框 | 完成或恢复 |
| 点击日程栏右侧“习惯” | 管理习惯、待办与提醒时间 |
| 月历上滚轮 | 切换月份 |
| 拖动顶部 | 移动挂件 |
| Ctrl+N / N / Enter | 打开当天完整事项详情 |
| Ctrl+T / T / Home | 回到今天 |
| Ctrl+G | 切换 Compact / Global 视图 |
| Ctrl+K | 搜索事项与快捷命令 |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做事项操作（非文本编辑时） |
| PageUp / PageDown | 切换月份 |
| 方向键 | 移动所选日期 |
| Esc | 结束临时前台并回到桌面层 |
| Compact 顶部横线 / Alt+F4 | 隐藏到通知区域，提醒继续运行 |
| Global 顶部横线 | 最小化到 Windows 任务栏 |
| 双击托盘图标 | 显示月历 |
| 右键托盘图标 | 新建、更新或完全退出 |

## 从源码运行

需要 Python 3.9 或更新版本，不依赖第三方运行库：

```powershell
pyw -3 app.py
```

也可以双击 `启动桌面月历.pyw`、`.vbs` 或 `.bat`。

## 构建发布包

安装 PyInstaller 后运行：

```powershell
py -3 -m pip install pyinstaller
powershell -ExecutionPolicy Bypass -File .\build_release.ps1
```

生成结果位于 `release/`。发布 Release 时必须同时上传 ZIP 和对应的 `.sha256` 文件，否则客户端会拒绝自动安装；另外上传独立的 `DesktopCalendarRepair.exe` 及其 `.sha256`，供主程序无法启动时单独下载。
